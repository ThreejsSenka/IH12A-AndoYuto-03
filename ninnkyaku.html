走れ！〇人〇脚！

開催時間：10:50～

集合場所

競技詳細

概要

・本競技は、25m往路と25m復路をリレー形式で走破する団体種目
・参加者は3～7の奇数グループに分かれ、1グループ最大4名で走行する
・1戦は8分間で行い、全体で6戦（計48分）実施。入れ替え時間を含めて約60分を予定
・競技は体育館コートの半面を使用し、もう反面では別の競技を同時進行する

対戦表

競技人数

1戦につき走者は12名
 -　1人の出走は1回のみとする
 -　一度に走る人数は最大4名まで

内容

  • ・各チームは、編成例に記載されている3、5、7グループのうちのいずれかで編成し、競技は「往路25m」「復路25m」を交互に走るリレー形式で行う
    ・先頭グループから順にスタートをし、先頭グループがラインを越えた時点で次のグループが出走、以降はあらかじめ定められた順番に従ってリレーを継続する

    走行形式（脚数）は以下の3種を用いる
    -　１人2脚：通常の個人走
    -　2人3脚：2人が足を結び、息を合わせて走るペア走
    -　4人5脚：4人が連結し、チームワークを要する団体走

    グループ編成と走順の例は以下の通り
    -　3グループ編成：往路4人5脚 → 復路4人5脚 → 往路4人5脚
    -　5グループ編成：往路1人2脚 → 復路1人2脚 → 往路2人3脚 → 復路4人5脚 → 往路4人5脚
    -　7グループ編成：往路4人5脚 → 復路2人3脚 → 往路2人3脚 → 残りの区間はすべて1人2脚

    ・全グループが順番に走り、最後の走者（アンカー）がゴールラインを越えた時点で競技は終了となる

ルール

  1. 1.グループ分け
    • -　各グループは最大4名まで
    • -　3.5.7グループ編成のいずれかを選択

  2. 2.競技の流れ
    • -　先頭グループから順にスタート
    • -　先頭グループがラインを越えたら次のグループがスタート
    • -　以降、グループの順番に従ってリレーを継続
    • -　最終走者（アンカー）がゴールラインを越えた時点で終了

  3. 3.編成例
    • - 3グループ編成

       往路：4人5脚　→　復路：4人5脚　→　往路：4人5脚

    • - 5グループ編成

       往路：1人2脚　→　復路：1人2脚　→　往路：2人3脚
       →　復路：4人5脚　→　往路：4人5脚

失格事項

  1. 1.出走・時間に関する違反
    • - 集合時間に遅れた場合（チームがそろわなかった場合は失格）
    • - １グループの人数制限（最大４名）を超えた場合
    • - 出走順やグループ編成を勝手に変更した場合
  2. 2.装備に関する違反
    • - アンカーがビブスを着用していない場合
    • - 結束用の鉢巻きが走行中に外れた場合
    • - 運営が危険と判断する結び方・装着不良
  3. 3.走行に関する違反
    • - コース外を走った、ショートカットした場合
    • - 他チームの走行を妨害した場合（押す・引っ張る・進路妨害など）
    • - スタート前のフライング
  4. 4.安全面に関する違反
    • - 故意に転倒を誘発する行為
    • - ふざけすぎて危険行為となった場合
    • - 運営の指示に従わなかった場合
